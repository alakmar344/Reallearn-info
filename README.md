# RealLearn

RealLearn transforms curiosity into structured learning journeys. Ask any question, get a guided 3-stage lesson with quizzes, and connect knowledge to today's world.

## About

RealLearn is a guided-learning platform that turns questions into structured journeys. Each journey has 3 progressive parts with quiz checks, ensuring understanding before advancement.

Built for learners who struggle with difficult topics, prefer learning in their native language, or want real-world context instead of abstract theory.

## Features

- **3-Stage Journey**: Foundation → Mechanism → Real World application
- **Quiz-Gated Progression**: Active recall verifies comprehension
- **8-Language Support**: Native generation in English, Hindi, Gujarati, Tamil, Bengali, Marathi, Telugu, Kannada
- **Adaptive Depth**: Three levels calibrated to learner capacity
- **Current Context**: Real-world events connect theory to practice

## Quick Start

```bash
# Terminal 1 — Backend
cd backend && npm install && npm start

# Terminal 2 — Frontend  
cd frontend && npm install && npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start learning.
