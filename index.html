What reallearn Is

reallearn is a guided-learning platform designed for students who need more than answers — they need understanding. It serves learners who struggle with difficult topics, feel alienated by language barriers, lack the feedback loops that confirm comprehension, and find theory disconnected from the world they live in.

Core philosophy: Don't just answer — teach. Structure knowledge into a deliberate journey, verify comprehension at every milestone, and anchor understanding to the real world. A question isn't the end of learning — it's the beginning.

The Problem We Solve

Traditional AI delivers one-shot answers: shallow, mismatched to the learner's level, detached from current reality, and forgotten within minutes. When a student asks "Why does the rupee depreciate?", a single paragraph about exchange rates teaches nothing that lasts. reallearn fundamentally reimagines this dynamic — replacing passive answers with staged teaching and mandatory comprehension checkpoints that transform information into lasting knowledge.

The gap isn't in access to information — it's in the architecture of understanding. Students don't need more content; they need guided progression, active recall, and real-world relevance. That's the gap reallearn was built to close.

End-to-End Learning Flow

Every reallearn session follows a carefully orchestrated pipeline — from raw curiosity to validated understanding. Here's the complete journey a question takes:

  1. Ask. A learner enters a question — any question that sparks curiosity.
  2. Configure. The learner selects their preferred language and depth level.
  3. Request. The frontend calls /api/generate-lesson with the full context.
  4. Ground. The backend fetches relevant real-world context when available — current events, recent developments, live data.
  5. Generate. Gemma 4 produces a structured 3-stage JSON journey, calibrated to the learner's level and language.
  6. Validate. The backend validates and, if necessary, repairs the model output through a 5-stage resilience pipeline.
  7. Render. The frontend presents all 3 parts, sources, and paired quizzes in a beautifully staged interface.
  8. Gate. Each quiz must be passed to unlock the next learning stage — comprehension isn't optional.
  9. Continue. The learner completes takeaways and can loop into a follow-up journey, diving ever deeper.

Feature Deep Dive

Every feature in reallearn exists for a reason — to close a specific gap in how learners actually absorb, retain, and apply knowledge. Nothing is decorative; everything is deliberate.

  • 3-Part Unlockable Journey — Foundation → Mechanism → Real World Now. Each stage builds on the last, creating a coherent arc from basics to breathless relevance.
  • Quiz-Gated Progression — 2 MCQs per stage, 4 options each. You don't advance until you demonstrate understanding — active recall in its purest form.
  • 8-Language Native Generation — English, Hindi, Gujarati, Tamil, Bengali, Marathi, Telugu, Kannada. Not translated — natively generated, culturally attuned.
  • Adaptive Depth Calibration — Three levels (Class 6–8, Class 9–10, College) with distinct vocabulary, complexity, and conceptual scaffolding.
  • Real-World Context Integration — Serper-powered current event anchoring turns abstract theory into living knowledge.
  • SSE Streaming with Heartbeat — Real-time server-sent events with keep-alive pings so learners see progress, not a blank screen.
  • Output Resilience Layer — 5-stage JSON repair and strict validation. The learner never sees a broken experience, even when the model stumbles.
  • Follow-Up Learning Loop — Every answer opens a door. Learners can continue their journey with follow-up questions, building depth iteratively.
  • Session-Persisted State — Progress survives refreshes. The learning journey respects the learner's time and attention.

Tech Stack

reallearn runs on a modern, performant, and resilient stack — chosen not for novelty, but for reliability at every layer of the learning experience.

Frontend — Vercel
Next.js 15 with React 19 and TypeScript for type-safe, performant UI. Zustand for lightweight state management. React Markdown for rich content rendering. Tailwind CSS for a precise, maintainable design system.
Backend — Render
Node.js with Express for robust API routing. SSE + JSON for real-time streaming. Gemma 4 integration via Gemini API. Serper for context enrichment. Full validation and repair layer for output resilience.

Architecture & Deployment

reallearn follows a clean two-service architecture, each optimized for its domain and deployed on infrastructure matched to its needs:

  • frontend/ → Next.js application deployed on Vercel — edge-optimized, globally distributed, instant cold starts.
  • backend/ → Express API deployed on Render — persistent compute for AI inference, streaming, and validation.
  • Primary endpoint: POST /api/generate-lesson — the core learning engine.
  • Health endpoint: GET /health — for uptime monitoring and readiness checks.

API Behavior & SSE Streaming

The lesson generation endpoint uses Server-Sent Events to stream progress in real-time, keeping learners informed and engaged throughout the generation process:

Event Purpose
event: ping Keep-alive heartbeat — prevents connection timeout during generation
event: lesson Final lesson payload — the complete 3-stage journey with quizzes and sources
event: done Successful stream end — signals completion to the client
event: error Failure message — graceful error communication with context

Environment Variables

reallearn is configured through environment variables, giving operators full control over AI model parameters, retry behavior, circuit breaking, and streaming behavior:

Frontend

  • NEXT_PUBLIC_BACKEND_URL — URL of the Render backend (e.g. https://<your-app>.onrender.com)
  • NEXT_PUBLIC_STREAM_IDLE_TIMEOUT_MS — Idle timeout for SSE stream (default: 120000ms, optional)

Backend — Core

  • GEMMA_API_KEY — Gemini API key for Gemma 4 access
  • GEMMA_MODEL — Model identifier (default: gemma-4-26b-a4b-it)
  • SERPER_API_KEY — Serper API key for real-world context enrichment
  • FRONTEND_ORIGIN — Allowed CORS origin (e.g. https://<your-app>.vercel.app)
  • PORT — Server port (default: 10000 on Render, optional)

Backend — Retry & Circuit Breaking (Optional)

  • GEMMA_MAX_RETRIES — Max retry attempts (default: 2)
  • GEMMA_RETRY_DELAY_MS — Initial retry delay (default: 700ms)
  • GEMMA_MAX_RETRY_DELAY_MS — Maximum retry delay cap (default: 5000ms)
  • GEMMA_TIMEOUT_CIRCUIT_FAILURE_THRESHOLD — Failures before circuit opens (default: 5)
  • GEMMA_TIMEOUT_CIRCUIT_COOLDOWN_MS — Circuit cooldown period (default: 60000ms)

Backend — Operational (Optional)

  • MAX_CONCURRENT_LESSON_REQUESTS — Concurrency limit (default: 3)
  • LESSON_FAILURE_ALERT_THRESHOLD — Failure count for alerting (default: 5)
  • SSE_HEARTBEAT_INTERVAL_MS — Heartbeat ping interval (default: 15000ms, capped at 55000ms)

Local Development

Getting reallearn running locally is straightforward — two terminals, two commands, and you're exploring the full learning experience: 

# Terminal 1 — Start the backend
cd backend
npm install
npm start

# Terminal 2 — Start the frontend
cd frontend
npm install
npm run dev
