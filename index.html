Part 02 · Mechanism

Powered by Gemma 4

RealLearn runs on Gemma 4 (gemma-4-26b-a4b-it) via Cloudflare Workers AI — wrapped in a prompting and reliability layer engineered to guarantee structure on every request.

15–25s
Average end-to-end generation time, with high structural integrity held constant across every request.

Structured Output Enforcement

A strict JSON schema forces exactly three parts, each with precisely two multiple-choice questions and exhaustive, teaching-grade explanations.

Native Multilingual Generation

Lessons are composed directly in the learner's language — never machine-translated. JSON keys stay in English so the app stays robust.

Adaptive Calibration

The same prompt reshapes vocabulary, examples, and rigor for Class 6–8 through College / Advanced.

Real-World Grounding via Serper

Recent, India-relevant news is fetched and injected before Gemma writes a word of Part 3.

Dual Prompt Architecture

Separate system prompts power the full Explain journey and the lightning-fast single-part Fast mode.

Robustness Engineering

A multi-stage JSON repair pipeline and lenient schema validation mean rough output still degrades into a coherent lesson.

Under the hood

Built like production software

Not a demo held together with tape — reliability, caching, safety, and security engineered in from the start.

Reliability
  • SSE streaming with keep-alive heartbeats
  • Smart retries with exponential backoff
  • Timeout circuit breaker + cooldown recovery
  • Concurrency caps & sliding-window rate limits
  • Fails open, degrades gracefully, never blocks
Two-Tier Caching
  • Tier 1 — in-memory LRU, 6-hour TTL
  • Tier 2 — MongoDB with TTL index, fleet-wide
  • Deterministic SHA-256 cache keys
  • A hit skips Serper, Gemma, and both moderation passes
Safety & Moderation
  • Regex input guard before anything reaches the model
  • LLM moderation layer, fail-open on timeout
  • Output re-screened on the way back
  • In-prompt refusal instructions, built for ages 13+
Security & Privacy
  • Clerk JWT verification, JWKS + offline PEM fallback
  • IDOR-safe: writes keyed to verified identity only
  • Hardened headers — CSP, HSTS, COOP, CORP
  • Full data export & one-click account deletion
