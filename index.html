Our Vision

Most AI tools just give you answers. We give you understanding.

reallearn breaks down complex topics into a 3-stage progression that respects your pace. Whether you're a middle-schooler or a college student, we calibrate the depth to match your capacity. A question isn't where learning ends — it's where real learning begins.

What reallearn Is

A guided-learning platform for students who need more than answers — they need understanding.

It serves the learner who struggles with difficult topics, the one alienated by language, and the one who reads but doesn't retain. reallearn is built for the curious mind.

Core philosophy: Don't just answer — teach. Structure knowledge into a deliberate journey, verify comprehension at every milestone, and anchor understanding to the real world.

The Problem We Solve

The gap isn't in access to information — it's in the architecture of understanding.

Traditional AI delivers one-shot answers: shallow, mismatched, and detached. Students don't need more content; they need guided progression, active recall, and real-world relevance. reallearn closes this gap with better architecture.

End-to-End Flow

  1. Ask. Enter any question that sparks curiosity.
  2. Ground. Fetch real-world context via Serper. Theory meets today.
  3. Generate. Gemma 4 composes a structured 3-stage journey.
  4. Validate. Run a 5-stage resilience pipeline for output quality.
  5. Render. Present stages, sources, and quizzes in a clean UI.
  6. Gate. Pass quizzes to unlock the next stage. Comprehension verified.

Tech Stack

Frontend — Vercel
Next.js 15, React 19, TypeScript, Zustand, Tailwind CSS.
Backend — Render
Node.js, Express, SSE, Gemma 4 (Gemini API), Serper.

Architecture & Deploy

  • frontend/ → Next.js on Vercel — edge-optimized.
  • backend/ → Express API on Render — persistent compute.
  • Core endpoint: POST /api/generate-lesson.
  • Health check: GET /health.

API & SSE Streaming

EventPurpose
event: pingKeep-alive heartbeat prevents connection timeout.
event: lessonFinal 3-stage journey payload with quizzes.
event: doneSignals successful stream completion.
event: errorGraceful error communication with context.

Environment Variables

Frontend

  • NEXT_PUBLIC_BACKEND_URL — Render backend URL.
  • NEXT_PUBLIC_STREAM_IDLE_TIMEOUT_MS — SSE timeout (default: 120000ms).

Backend

  • GEMMA_API_KEY — Gemini API key for Gemma 4.
  • SERPER_API_KEY — Context enrichment via Serper.
  • FRONTEND_ORIGIN — Allowed CORS origin.
