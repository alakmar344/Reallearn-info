AI Engine

Powered by Gemma 4

RealLearn runs on Gemma 4 (26B) via the Gemini API — with a sophisticated prompting and reliability layer that guarantees educational quality on every request.

🎯

Structured Output

A strict JSON schema ensures exactly three progressive parts, each with two multiple-choice questions.

🌐

Native Multilingual

Lessons are generated directly in the learner's language — never machine-translated afterward.

📈

Adaptive Calibration

Depth, vocabulary, and complexity adjust dynamically based on the selected level.

📰

Real-World Context

Robustness Engineering

Fast & Reliable

Technology

Built Like Production Software

Not a demo held together with tape. RealLearn is engineered with resilience, safety, and privacy at every layer.

🖥️ Frontend

Deployed on Vercel

  • • Next.js 15 (App Router)
  • • React 19 + TypeScript
  • • Clerk Authentication
  • • Zustand with persist middleware
  • • React Markdown + remark-gfm
  • • Tailwind CSS with token-based design
Next.js React TypeScript Clerk Zustand Tailwind

⚙️ Backend

Deployed on Render

  • • Node.js + Express (ES Modules)
  • • SSE Streaming with keep-alive
  • • Gemma 4 via Gemini API
  • • Serper News API
  • • Clerk JWT verification (jose)
  • • MongoDB for consent & logs
Node.js Express SSE Gemma 4 MongoDB Jose

🛡️ Safety & Moderation

Input/output filtering, in-prompt guardrails, safety-finish handling, and moderation logging — built for learners 13+.

🔒 Security & Privacy

Clerk authentication, hardened HTTP, data export, account deletion, transparent consent, and a full legal suite.

Reliability

Engineered to Stay Up

Streaming, retries, circuit breakers, rate limiting, and graceful degradation — built for production.

📡

SSE Streaming

Server-Sent Events with periodic ping heartbeats.

🔄

Smart Retries

Exponential backoff on 429 and 5xx with circuit breaker protection.

⏱️

Timeout Protection

A circuit breaker fast-fails new requests for a cooldown window on repeated timeouts.

🚦

Concurrency Control

Caps simultaneous generations — returns a friendly busy message instead of collapsing.

🛑

Rate Limiting

Per-user (or per-IP) limits with a sliding window and automatic cleanup.

📊

Failure Alerting

Consecutive failures are tracked and logged — with recovery signals for clear operations.
